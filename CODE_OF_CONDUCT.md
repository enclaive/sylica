# Code of Conduct

## Our Commitment

Sylica is an open-source project built around security, transparency, technical excellence, and collaboration.

We are committed to providing a welcoming, respectful, and professional environment for everyone who contributes to or
participates in the project, regardless of background, identity, experience level, or role.

We expect all participants to contribute constructively and to treat others with respect.

## Expected Behaviour

Participants are expected to:

* Be respectful and professional in discussions and reviews.
* Assume good intent while addressing disagreements constructively.
* Focus criticism on ideas, implementations, and technical decisions rather than individuals.
* Provide actionable and technically grounded feedback.
* Welcome questions and contributions from people with different levels of experience.
* Respect differing technical opinions and approaches.
* Keep discussions relevant to the project.
* Protect confidential, proprietary, and security-sensitive information.
* Follow the project's security disclosure process when reporting vulnerabilities.
* Accept constructive feedback and decisions made by project maintainers.

## Unacceptable Behaviour

The following behaviour is not acceptable:

* Harassment, discrimination, intimidation, or personal attacks.
* Threats or deliberately hostile behaviour.
* Trolling, deliberate disruption, or repeated bad-faith participation.
* Publishing private or confidential information without permission.
* Sharing security-sensitive information through inappropriate public channels.
* Deliberately misrepresenting another contributor's statements or work.
* Sustained unreasonable demands or abusive communication towards maintainers or contributors.
* Any other behaviour that would reasonably be considered inappropriate in a professional technical community.

## Technical Disagreements

Sylica is a security-critical project, and strong technical disagreement is expected.

Disagreement about:

* architecture;
* security assumptions;
* TCB composition;
* implementation choices;
* performance;
* reproducibility;
* platform support;
* upstream integration;

is welcome.

However, disagreements must remain focused on the technical issue.

A contributor may strongly challenge an implementation or architectural decision without attacking the person who proposed it.

## Security Discussions

Sylica deals with confidential computing, firmware, trusted computing bases, attestation, and platform security.

Security discussions require particular care.

Do not publicly disclose vulnerabilities, exploit details, credentials, private keys, confidential customer information,
or other sensitive information through GitHub issues, pull requests, or public discussions.

Follow [`SECURITY.md`](SECURITY.md) for security vulnerability reporting.

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Maintainers may take appropriate action in response to unacceptable behaviour, including:

* requesting that a participant change their behaviour;
* removing inappropriate comments or contributions;
* temporarily restricting participation;
* closing discussions or issues;
* rejecting pull requests;
* restricting or removing repository access;
* permanently banning participation in the project.

Actions will be proportionate to the behaviour and its impact on the project community.

Maintainers may consider the context, severity, frequency, and intent when determining an appropriate response.

## Reporting

If you experience or witness behaviour that violates this Code of Conduct, report it privately to the project maintainers.

Do not use public GitHub issues or pull requests for sensitive reports.

For security vulnerabilities, use the dedicated process in [`SECURITY.md`](SECURITY.md).

For non-security Code of Conduct concerns, contact the project maintainers through the private contact channel specified by the repository.

Please include:

* a description of what happened;
* relevant dates or locations within the project;
* links or references to relevant discussions where appropriate;
* any other information that can help the maintainers understand the situation.

Reports will be handled as confidentially as reasonably possible.

## Scope

This Code of Conduct applies to:

* the Sylica repository;
* GitHub issues, pull requests, and discussions;
* project-related communication channels;
* project-related events and meetings;
* other spaces where an individual is representing the Sylica project.

Project maintainers may address behaviour outside these spaces when it has a material impact on the safety or functioning of the Sylica community.

## Attribution

This Code of Conduct is based on common principles used by open-source communities and has been adapted for the security-critical nature of the Sylica project.
